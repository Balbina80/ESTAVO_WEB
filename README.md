# Estavo Website v1.0

First public-release website for **Estavo**, a connected business workspace by BJ Precision Business Solutions Ltd.

## Included

- Responsive landing page
- Interactive industry workspace previews
- Estavo AI product preview
- Early-access, demo, login and registration-interest modals
- Privacy Policy and Website Terms
- Open Graph and social-sharing metadata
- Favicon, web manifest, robots.txt and sitemap.xml
- Branded 404 page
- GitHub-ready project structure

## Local preview

Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before public launch

The forms are currently front-end demonstrations and do not transmit or store personal data. Connect them to an approved form service or backend before accepting submissions. Review the legal pages before launch and add analytics only after an appropriate cookie-consent solution is in place.
