SECURITY & TRUST

Responsible access. Clear controls. Honest claims.

Estavo is being developed around secure authentication, role-based access and workspace-level data separation. We will publish verified production details before commercial launch.

ACCESS

Individual accounts

Users are invited to create their own password rather than sharing credentials.

PERMISSIONS

Role-based access

Roles are designed to limit access according to responsibilities.

ISOLATION

Workspace separation

Customer records are designed to be separated at workspace level using database access controls.

TRANSPORT

Encrypted connections

Production services are intended to use HTTPS and managed authentication providers.

ROADMAP

Audit logs

Expanded audit and activity reporting is part of the launch roadmap and should not be treated as fully released yet.

TRANSPARENCY

Launch documentation
